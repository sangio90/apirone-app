Seleziona il valore corretto per ogni select nell'albero
================================================

A questa riga:

```
await viewModel.loadProductItems(qipi.productItem.id, qipi.productItem.attribute.id);
```

vengono caricate le options di un attributo del prodotto.  

Devi fare in modo che venga selezionata l'opzione corretta.

File coinvolti:

- quotation-plate.cfm
- app-quotation-plate.js
- app-quotation-detail.js
- quotation.css
